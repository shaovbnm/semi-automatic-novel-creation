# 短篇题材框架

短篇题材框架只提供方向，不替故事加世界观。

选题时先选核心情绪，再选题材壳。

## 复仇打脸

核心情绪：憋屈、压抑、爽。

常用开局：婚礼羞辱、家宴逼迫、公司甩锅、直播翻车、遗嘱争夺。

关键物件：录音、监控、合同、转账、聊天记录、亲子鉴定、遗嘱。

反转：主角不是没证据，而是在等公开场合。

结尾：反派当众塌房，主角不解释太多。

## 虐恋反转

核心情绪：心疼、误会、迟来的后悔。

常用开局：替身、白月光回国、离婚协议、病危通知、错过的电话。

关键物件：旧照片、病历、未发出的消息、录音、戒指、孩子的东西。

反转：被伤害的一方早已付出代价，或者所谓背叛另有隐情。

结尾：可以不原谅，不要强行团圆。

## 家庭亲情

核心情绪：委屈、被偏爱伤害、身份反转。

常用开局：真假千金、重男轻女、遗产分配、生日宴、病房签字。

关键物件：户口本、出生证明、旧衣服、转账记录、监控、DNA 报告。

反转：被嫌弃的人才是撑起家的那一个，或被宠的人早有算计。

结尾：断亲、清算、离开，情绪要干净。

## 悬疑惊悚

核心情绪：不对劲、害怕、后知后觉。

常用开局：邻居异常、外卖备注、旧楼电梯、重复短信、失踪好友。

关键物件：门禁记录、脚印、监控盲区、照片里多的人、电话录音。

反转：异常不是鬼，或比鬼更现实；也可以是规则本身有问题。

结尾：留一个冷钩，不解释光。

## 职场现实

核心情绪：窒息、反击、讽刺。

常用开局：替同事背锅、裁员名单、年会羞辱、老板画饼、客户甩锅。

关键物件：邮件、工牌、会议纪要、录屏、考勤、劳动合同。

反转：主角掌握完整证据链，或者客户 / 甲方身份反转。

结尾：现实爽感，不要写成成功学。

## 规则 / 脑洞

核心情绪：新奇、紧张、反常。

常用开局：收到奇怪规则、每天身份变化、系统任务、房间禁忌。

关键物件：规则纸条、倒计时、门牌、手机弹窗、重复物品。

反转：规则不是限制主角，而是暴露别人。

结尾：回收第一条规则。

## 选择题

确定题材前问三句：

1. 读者最先为什么停下？
2. 读者中途最想知道什么？
3. 读者看完最想转述哪一句？

答不上来，就不是短篇好选题。
