# 短篇拆文：爆款公式

短篇公式用于拆解，不用于机械套作。

## 常见公式

### 复仇打脸

公开羞辱 → 主角忍住 → 对方加码 → 证据出现 → 当众反杀 → 关系切割。

### 虐恋后悔

误会压迫 → 主角受伤 → 对方选择别人 → 旧物/病历揭露 → 对方后悔 → 主角不回头。

### 亲情断亲

偏心场景 → 主角被牺牲 → 被宠者露破绽 → 身份/证据反转 → 家人求和 → 主角离开。

### 悬疑异常

日常异常 → 合理化解释 → 第二异常 → 主角验证 → 真相翻面 → 冷感收尾。

### 职场反击

甩锅 → 群体沉默 → 主角被逼签字/背责 → 证据链补齐 → 公开翻盘 → 离职/清算。

## 拆文输出

每篇短篇拆成：

```markdown
## 故事公式

- 开局压迫：
- 中段加码：
- 误导方式：
- 真线索：
- 反转揭露：
- 结尾兑现：
```

## 注意

公式只抽结构，不照搬人物、标题和具体桥段。
