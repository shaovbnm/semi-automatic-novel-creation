# 短篇拆文：市场对照

拆短篇时，将作品结构和平台偏好对照，判断是否值得学习。

## 平台偏好

| 平台 | 偏好 | 拆解重点 |
|---|---|---|
| 番茄短篇/活动文 | 标题直、情绪强、反转清楚、完读率 | 开头冲突、爽点密度、反转易懂度 |
| 知乎盐言 | 关系反转、现实共鸣、标题传播 | 叙述钩子、付费节点、情绪纵深 |
| 七猫短篇 | 快节奏、强冲突、低理解成本 | 每节事件密度、人物关系直观度 |
| 黑岩短篇 | 悬疑、复仇、极端情绪 | 异常设计、反转频率、压迫感 |
| 点众短篇 | 家庭/婚恋/复仇，快进快出 | 标题模式、反杀节点、证据链 |

## 拆解判断

一篇短篇是否值得学，看：

1. 开头是否三句内立住。
2. 情绪是否明确。
3. 反转是否能一句话讲明。
4. 中段是否不塌。
5. 结尾是否有传播点。

## 输出

给出：

- 平台适配度。
- 最值得学的 1-3 个点。
- 不建议照搬的点。
- 可转化为新选题的方向。
