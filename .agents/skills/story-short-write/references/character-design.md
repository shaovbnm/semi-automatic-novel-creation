# 短篇人物设计

短篇人物不靠完整成长弧吸引读者，而靠关系压力、秘密、选择和反转。

人物要少，但功能要准。

## 人物数量

常规短篇建议：

- 主角：1 人。
- 核心关系人：1 人。
- 反派或施压者：1 人。
- 工具型证人 / 误导人物：0-2 人。

超过 5 个重要人物，读者记忆成本会明显升高。

## 人物表写法

| 角色 | 表面身份 | 真实功能 | 欲望 | 隐瞒 | 结局 |
|---|---|---|---|---|---|

重点不是人设多丰富，而是每个人有没有推动：

- 情绪压迫。
- 信息误导。
- 反转揭露。
- 爽点兑现。

## 主角设计

短篇主角必须有一个强代入入口。

常见入口：

1. 被背叛。
2. 被误解。
3. 被替代。
4. 被剥夺。
5. 被迫忍耐。
6. 手里藏着一张底牌。
7. 看似输光，其实在等证据齐。

主角不需要从弱变强很多次。

主角需要在关键处做一次让读者爽的选择。

## 关系人设计

关系人比身份更重要。

优先选择有情绪拉扯的关系：

- 前任 / 现任。
- 亲生 / 养女。
- 闺蜜 / 替身。
- 夫妻 / 未婚夫妻。
- 母女 / 父女。
- 上下级 / 甲乙方。
- 救命恩人 / 加害者。

关系必须带债：情债、命债、钱债、名声债、亲情债。

## 反派设计

短篇反派不要写复杂成长史。

反派只需要三件事：

1. 有压迫感。
2. 有可被揭穿的谎。
3. 结局能被精准反噬。

反派越会装，反转越有劲。

反派越占道德高地，打脸越爽。

## 隐瞒设计

每个关键人物最好有一个隐瞒。

隐瞒分三类：

- 事实隐瞒：谁做了什么。
- 关系隐瞒：谁和谁真实关系不一样。
- 动机隐瞒：看似为爱，其实为利；看似背叛，其实保护。

短篇只选 1 个主隐瞒，不要套娃太多。

## 禁忌

- 不给每个人写长背景。
- 不让配角抢主角情绪线。
- 不用人物小传代替剧情。
- 不把反派写成纯解释机器。
- 不为了反转强行改人物立场。
