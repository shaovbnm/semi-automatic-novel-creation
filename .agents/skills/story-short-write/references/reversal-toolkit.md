# 短篇反转工具箱

短篇反转不求多，求准。

一个核心反转打透，比三个小反转更有效。

## 反转基本结构

1. 表层真相：读者以为发生了什么。
2. 误导线索：让这个以为看起来合理。
3. 真线索：前文埋过，但不显眼。
4. 揭露动作：通过证据、对话破绽或物件翻面。
5. 情绪兑现：主角反击、对方后悔、真相变冷。

## 常用反转类型

### 1. 身份反转

表面：主角是外人、替身、失败者。

真实：主角才是关键继承人、救命恩人、真正掌权者、被隐瞒的受害人。

适合：真假千金、豪门、职场、婚恋。

### 2. 动机反转

表面：某人背叛主角。

真实：他在保护主角，或他根本不是为爱，而是为钱 / 权 / 名声。

适合：虐文、悬疑、亲情。

### 3. 证据反转

表面：证据证明主角有错。

真实：证据被剪辑、时间线被调换、关键片段被删。

适合：直播、舆论、职场、校园。

### 4. 受害者反转

表面：对方是受害者。

真实：对方在扮弱，主角才是被长期伤害的人。

适合：白莲、家庭、闺蜜、替身。

### 5. 规则反转

表面：规则限制主角。

真实：规则是主角用来筛出真凶或反杀的工具。

适合：规则怪谈、脑洞、悬疑。

## 误导线索

误导线索要合理，不能骗作者自己。

常用误导：

- 只给半截聊天记录。
- 只看到监控结果，不给前因。
- 某人故意替别人背锅。
- 主角沉默，让别人以为她认了。
- 物件出现，但用途被误解。

## 真线索

真线索要轻。

可以是：

- 一句没人接的话。
- 一个日期。
- 一张照片里的细节。
- 一个称呼。
- 一个迟到的电话。
- 一次反常沉默。

真线索不能到结尾才凭空出现。

## 揭露方式

优先级：

1. 对方自己说漏。
2. 证据当众播放。
3. 物件回收。
4. 第三方证人出现。
5. 主角最后补刀。

少用主角长篇解释。

## 反转失败原因

- 前文没有真线索。
- 误导太明显，读者早猜到。
- 结尾突然加新设定。
- 反转只惊讶，不带情绪。
- 反转后没有清算或余味。

## 检查句

写完反转后问：

1. 读者回看前文，会不会觉得“原来如此”？
2. 主角情绪有没有被兑现？
3. 反派有没有被自己的行为反噬？
4. 有没有靠解释撑反转？
5. 结尾有没有留一点余味，而不是讲道理？
