# 短篇情绪曲线

短篇先定情绪，再定剧情。

读者追短篇，追的是一口气：憋屈、怀疑、心疼、爽、后怕、回味。

## 常用情绪曲线

### 1. 憋屈到反杀

适合：复仇、背叛、替身、婚恋、家庭压迫。

节奏：

1. 开头被压。
2. 主角忍住。
3. 对方加码。
4. 证据露出。
5. 主角反手。
6. 反派被自己说过的话反噬。

### 2. 心疼到真相

适合：虐文、误会、亲情、救赎。

节奏：

1. 主角被误解。
2. 读者知道一点委屈。
3. 对方继续伤人。
4. 旧物 / 病例 / 录音揭开真相。
5. 对方后悔。
6. 主角不一定原谅。

### 3. 怀疑到惊悚

适合：悬疑、怪谈、现实反转。

节奏：

1. 日常里出现异常。
2. 异常被合理化。
3. 第二个异常推翻解释。
4. 主角验证。
5. 真相露出。
6. 结尾留下冷感回钩。

### 4. 荒诞到讽刺

适合：规则怪谈、现实讽刺、职场、家庭群像。

节奏：

1. 规则反常。
2. 众人接受。
3. 主角被迫配合。
4. 规则露出利益链。
5. 主角反用规则。
6. 收尾留讽刺感。

## 情绪强度表

| 阶段 | 情绪 | 强度 | 读者问题 |
|---|---|---:|---|
| 开头 | 被压 / 异常 | 7 | 她为什么忍？ |
| 中前 | 怀疑 / 憋屈 | 6 | 到底谁在骗她？ |
| 中段 | 加压 / 误导 | 8 | 她还有底牌吗？ |
| 反转 | 震出真相 | 9 | 原来前面都是伏笔？ |
| 结尾 | 爽 / 冷 / 回味 | 7 | 这个结局有后劲 |

## 写情绪的方法

不要直接写情绪名。

用：

- 物件：戒指、病历、旧手机、请柬、钥匙。
- 动作：没接、删掉、按停、退回、放下。
- 沉默：电话静了、饭桌静了、群聊没人说话。
- 误操作：打错字、发错人、点开又关掉。

## 禁忌

- 不在开头铺长回忆。
- 不让情绪一直同一个强度。
- 不把主角写成只会哭。
- 不把反转写成纯设定翻牌。
- 不在结尾强行升华。
