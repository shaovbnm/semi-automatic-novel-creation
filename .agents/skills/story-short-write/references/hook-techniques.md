# 短篇钩子技巧

短篇钩子要快、准、能立刻制造读者问题。

前三句必须有冲突、异常、反常行为或关系压迫。

## 开头钩子类型

### 1. 当众羞辱

> 婚礼进行到一半，我的新郎把戒指戴到了我妹妹手上。

读者问题：她会怎么反击？妹妹凭什么？

### 2. 反常行为

> 我妈死后第三天，她给我点了一份外卖。

读者问题：死人怎么点外卖？

### 3. 身份错位

> 我被亲生父母接回家那天，他们让我先给养女道歉。

读者问题：谁才是外人？

### 4. 时间压迫

> 离婚冷静期最后一天，我收到了丈夫的病危通知。

读者问题：要不要去？病危是真是假？

### 5. 规则异常

> 入住第一晚，房东发来三条规矩：凌晨两点后，别相信我。

读者问题：房东为什么不能信？

## 节尾钩子

每 800-1200 字最好有一个小钩子。

常用方式：

- 新证据出现。
- 旧证据反向解释。
- 关系人说漏嘴。
- 主角底牌露一角。
- 对方加码羞辱。
- 看似胜利后出现更大问题。

## 钩子句模板

这些是结构，不是固定句式，写时要换成具体内容。

- 我直到那一刻才发现，照片里少了一个人。
- 他忘了，录音还没关。
- 群里安静了三秒。
- 我把第二份报告递了过去。
- 门外的人，叫出了我的旧名字。
- 那个号码，我妈生前用过。

## 好钩子的标准

| 标准 | 说明 |
|---|---|
| 短 | 一两句话能说清 |
| 具体 | 有人、有物、有动作 |
| 有问题 | 读者会追问下一句 |
| 有情绪 | 不只是设定新奇 |
| 能回收 | 后文可以解释或反转 |

## 坏钩子

- 纯设定：这个世界有一种神秘力量。
- 纯感慨：我从没想过人生会这样。
- 纯悬浮：命运在此刻发生改变。
- 纯标题党：谁也不知道，更大的阴谋来了。

## 检查

写完开头后，只看前三句：

1. 有没有具体冲突？
2. 有没有让读者想问的问题？
3. 有没有关系压力？
4. 有没有一句可以当标题宣传点？

少一项，就重写。
