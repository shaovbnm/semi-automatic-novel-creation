# 短篇开头设计

短篇开头不铺世界观，不解释人物履历，不从“我叫某某”开始。

直接把读者扔进事里。

## 前三句要求

前三句至少包含一种：

1. 冲突。
2. 异常。
3. 关系压迫。
4. 反常行为。
5. 公开羞辱。
6. 即将失去的东西。

## 开头结构

### 第一段：事件砸脸

用最短的方式告诉读者：出事了。

> 我生日那天，丈夫把我的蛋糕送给了他的小青梅。

### 第二段：关系压迫

告诉读者这事为什么疼。

> 他说她刚回国，受不得委屈。

### 第三段：主角反应 / 反常点

不要急着解释，给一个动作或反常选择。

> 我点点头，把蜡烛一根根拔下来，放进包里。

读者会问：她为什么这么冷静？蜡烛有什么用？

## 常用开场场景

- 婚礼。
- 家宴。
- 葬礼。
- 病房。
- 公司会议。
- 直播间。
- 警局门口。
- 电梯 / 楼道 / 出租屋。
- 生日宴。
- 离婚登记处。

这些场景天然有压力，不需要长铺垫。

## 开头不要做

- 不从童年经历写起。
- 不从天气和环境写起。
- 不先介绍世界观。
- 不先讲人物长相。
- 不用三段心理独白。
- 不把反转提前解释掉。

## 开头信息量

开头只给必要信息：

- 谁压谁。
- 为什么当下危险或难堪。
- 主角有什么反常反应。

不要一次给：全部前史、所有人物关系、完整动机、最终真相。

## 开头自检

写完后问：

1. 如果只看前三句，读者会不会停下？
2. 主角的处境是不是够明确？
3. 有没有一句废话？
4. 有没有解释太早？
5. 有没有一个后面能回收的物件或动作？

不满足就先改开头，不要继续往后水。
