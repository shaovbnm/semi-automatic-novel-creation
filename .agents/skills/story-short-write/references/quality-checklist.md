# 短篇质量检查表

短篇检查只看能不能读完、情绪够不够、反转能不能成立。

不要按长篇标准检查世界观完整度。

## 结构检查

- 开头前三句是否有冲突、异常或压迫。
- 是否只有一个主钩子。
- 是否围绕一个主情绪推进。
- 中段是否每 300 字有新信息、冲突或情绪变化。
- 每 800-1200 字是否有小钩子。
- 结尾是否回收核心伏笔。
- 是否没有扩成长篇支线。

## 情绪检查

- 主角委屈 / 爽 / 怕 / 恨的来源是否具体。
- 情绪是否通过动作、对话、物件体现。
- 有没有连续三段都是心理活动。
- 有没有直接命名太多情绪。
- 反派压迫是否够早出现。
- 爽点是否真的兑现。

## 反转检查

- 反转前是否有误导线索。
- 真线索是否至少出现过一次。
- 反转是否能用前文证据解释。
- 有没有纯靠新设定硬翻盘。
- 揭露时是否避免说明书。
- 反转后是否有情绪余波。

## 人物检查

- 人物数量是否过多。
- 每个重要人物是否有明确功能。
- 反派是否有可被反噬的行为或谎言。
- 主角是否有主动选择。
- 关系压力是否清楚。

## 文风检查

- 是否一句一段，段落长短有变化。
- 对话是否独立成行。
- 是否有大段背景解释。
- 是否有 AI 套话。
- 是否把口语改得太书面。
- 结尾是否升华讲道理。

## 平台检查

| 平台 | 重点 |
|---|---|
| 盐言 / 知乎故事 | 开头强钩子、关系反转、标题传播性 |
| 番茄短篇活动 | 情绪清晰、类型明确、爽点密集 |
| 七猫短篇 | 节奏快、冲突直、反转易懂 |
| 黑岩短篇 | 悬疑、复仇、强情节推进 |
| 点众短篇 | 强情绪、强关系、低理解成本 |

## 最后一遍

删掉：

- 解释性情绪。
- 无功能回忆。
- 没有推动的配角。
- 漂亮但没用的句子。
- 结尾感悟。

保留：

- 半句话。
- 停顿。
- 不那么工整但有现场感的反应。
- 狠话。
- 能让读者转述的场面。
