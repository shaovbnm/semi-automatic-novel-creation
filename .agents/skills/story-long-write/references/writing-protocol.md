# 长篇正文写作协议

用于约束正文写入、上下文读取、写后检查和真人化处理。

## 写前读取顺序

写新章前必须读取：

1. `05_追踪/文风基准.md`
2. `正文/正文索引.md`
3. 最近 3-5 章正文
4. 当前卷卷纲：`03_大纲/卷纲_第X卷.md` 或旧路径 `大纲/卷纲_第X卷.md`
5. 当前批次细纲：`03_大纲/细纲_第X卷*.md` 或旧路径 `大纲/细纲_第X卷*.md`
6. `05_追踪/伏笔表.md`
7. `05_追踪/时间线.md`
8. 本章相关角色设定

## 正文写入

正文必须写入：

```text
正文/第XX卷_卷名/第XXX章_章名.md
```

单章文件只放可发布正文，不放分析、细纲、自评、检查报告。

## 字数规则

按章节功能落在对应区间内即可，不卡固定数字。

| 类型 | 字数区间 |
|---|---:|
| 开局立钩 | 3300-3800 |
| 常规推进 | 3600-3900 |
| 铺垫蓄压 | 3700-4100 |
| 爆点释放 | 3700-4200 |
| 卷尾高潮 | 4000-4500 |

不足时补有效剧情、冲突、动作和信息；超长时删解释、重复心理和低效对白。

## 文风一致性

写作时对照文风基准和最近 3-5 章，保持：

- 人称。
- 视角距离。
- 句长。
- 段落节奏。
- 对白密度。
- 角色语气。
- 情绪表达方式。
- 爽点释放方式。
- 章尾钩子方式。

禁止写着写着变成另一种书。

## 写后检查

每章写完默认检查：

1. 字数是否落在章节功能区间。
2. 是否完成本章细纲任务。
3. 章尾是否有追读钩子。
4. 是否有 AI 味：套话动作、情绪解释、说明书对白、结尾升华、段落过齐。
5. 是否与最近 3-5 章文风一致。
6. 是否与前文剧情、伏笔、时间线冲突。

## 真人化联动

长篇写后默认按 `story-deslop` 的 light 强度检查。

只削 AI 味，不改剧情，不扩设定，不替角色补动机，不破坏原书味。

如果修文导致文风漂移，必须改回文风基准。

## 更新文件

通过检查后更新：

- `正文/正文索引.md`
- `05_追踪/伏笔表.md`
- `05_追踪/时间线.md`
- 必要时补充 `05_追踪/文风基准.md`
