# 长篇项目状态协议

用于在执行长篇写作、续写、修文、检查前判断项目当前状态。

## 必查文件

执行任何正文相关任务前，优先检查：

- `00_项目说明.md`
- `02_设定/核心设定.md`
- `03_大纲/总纲.md`
- `03_大纲/卷纲_*.md`
- `03_大纲/细纲_*.md`
- `正文/正文索引.md`
- `正文/第XX卷_卷名/`
- `05_追踪/文风基准.md`
- `05_追踪/伏笔表.md`
- `05_追踪/时间线.md`

如果旧项目仍使用 `设定/`、`大纲/`、`追踪/`，先兼容读取；新建项目按 `02_设定/`、`03_大纲/`、`05_追踪/` 创建。

## 任务识别

| 用户意图 | 判断依据 | 下一步 |
|---|---|---|
| 开新书 | 没有项目文件或用户说开书 | 先做番茄开题评分和核心设定 |
| 写总纲 | 有核心设定但无总纲 | 生成 `03_大纲/总纲.md` |
| 写卷纲 | 有总纲但缺当前卷 | 生成 `03_大纲/卷纲_第X卷.md` |
| 写细纲 | 有卷纲但缺章级安排 | 生成批次细纲 |
| 写正文 | 有细纲和正文索引 | 定位卷/章，读取上下文后写入正文文件 |
| 续写 | 已有正文 | 读取最近 3-5 章、索引、文风基准、当前细纲 |
| 修文 | 用户指定已有正文 | 保留剧情和文风，只修错字、AI 味、冲突和节奏 |
| 检查节奏 | 用户要检查 | 对照卷纲、细纲、正文索引和文风基准 |

## 正文分卷目录

展示名：

```text
第1卷：午夜第一单
第2卷：清账人
```

文件夹名：

```text
正文/第01卷_午夜第一单/
正文/第02卷_清账人/
```

正文文件：

```text
正文/第01卷_午夜第一单/第001章_午夜第一单.md
```


## 状态判断

写新章前必须知道：

1. 当前卷。
2. 当前章号。
3. 上一章结尾钩子。
4. 当前章细纲任务。
5. 当前文风基准。
6. 待回收伏笔。
7. 当前时间线位置。

缺少这些信息时，先补最小可用状态，再写正文。
