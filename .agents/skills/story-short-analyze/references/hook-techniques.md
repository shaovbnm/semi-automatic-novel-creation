# 短篇拆文：钩子识别

拆短篇钩子时，重点看读者为什么会继续读下一段。

## 开头钩子

记录前三句：

```markdown
原文前三句：
1. 
2. 
3. 

钩子类型：冲突 / 异常 / 关系压迫 / 公开羞辱 / 身份错位 / 规则异常
读者问题：
```

## 中段钩子

每 800-1200 字记录一次：

| 位置 | 新信息 | 情绪变化 | 读者问题 | 是否有效 |
|---|---|---|---|---|

## 结尾钩子

判断结尾属于：

- 爽点收束。
- 冷感回钩。
- 物件回收。
- 反派反噬。
- 开放式余味。

## 好钩子标准

- 短。
- 具体。
- 有关系压力。
- 能形成读者问题。
- 后文能回收。

## 复用输出

拆文报告最后给出：

1. 可复用开头模式。
2. 可复用节尾钩子。
3. 不建议复用的标题党钩子。
